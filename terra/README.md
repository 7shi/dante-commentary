# terra

`openai:gpt-5.6-terra` による出力。地獄篇第1〜5歌。[`scripts/fix_brackets.py`](../scripts/fix_brackets.py) と [`scripts/fix_quote_blocks.py`](../scripts/fix_quote_blocks.py) は適用済み、[ALIGNMENT.md](../ALIGNMENT.md) の後処理（引用の追加・節の並べ替え・見出しへの行範囲付与）は未適用。

```
uv run scripts/generate.py inferno -c 1-5 -m openai:gpt-5.6-terra -d terra
```

- `01.md`〜`05.md` … 解説記事（commentary）
- `01.txt`〜`05.txt` … 全行の日本語翻訳テキスト。`NN.md` の引用ブロックから抽出した訳を種にして、残りを補完させたもの

## 講評

**内容の水準は [astra](../astra/README.md) と互角で、残る差は引用量に集中している。** 解説の事実関係はほぼ正確で、翻訳テキストも5歌すべて破綻なく埋まっている。一方、引用が全行に近い量に膨らむ点は astra と明確に異なる。

比較にあたっては、**astra は [ALIGNMENT.md](../ALIGNMENT.md) の後処理を経ており、terra は未処理である**ことに注意が必要である。後処理では、本文が言及しているのに引用が欠けている箇所への引用追加、節の時系列順への並べ替え、見出しへの行範囲の付与（`## N. タイトル（X～Y行）`）が行われている。以下の astra の数値はこれらを含んだ後の値である。

### 数値の比較

| 第1歌 | 136 | 136 (100%) | 7 | 68% | 92 (67%) | 20 | 57% |

「引用比」は記事の文字数に占める引用ブロックの割合。ALIGNMENT.md の作業記録によれば、astra の引用は後処理で第1歌16行・第2歌3行・第3歌9行・第5歌6行が追加されているので、生成直後の被覆はさらに低い（第1歌で56%程度）。それでも terra は5歌すべてで引用が地の文を上回り、ブロック数は astra の半分以下である。この差は後処理では説明されない。

### 見出しの行範囲――後処理が未適用

[`templates/build.py`](../templates/build.py) の `parse_commentary` は、各 `##` 見出しの担当行範囲を**見出しのテキストから**読み取る（`HEAD_RE`、`（31～48行）` の形式）。範囲が1..nを隙間なく覆わなければ `commentary headings don't tile` として、そのカントは注釈なしの本文だけで出力される。terra は5歌ともここで弾かれる。

ただしこれはモデルの差ではない。この行範囲は ALIGNMENT.md ④の後処理で付与されたものであり、`PROMPT`（[`scripts/generate.py`](../scripts/generate.py)）は見出しの書式を指定していない。astra も生成直後は同じ状態だったはずで、terra をサイトに載せるなら同じ後処理を通せばよい。

terra 固有の事情として記録しておく点は2つ。

- 第2歌だけは `（1–9行）` と範囲を自発的に書いているが、区切りが **EN DASH（U+2013）** で、`HEAD_RE` が受け付ける `～` と ASCII ハイフンのどちらでもない。後処理④の標準化対象になる
- 第3歌は節が担当する引用範囲そのものが重なっている（第6節が46〜60行、第7節が52〜69行）。行範囲を確定する際に重複の解消が必要になる（ALIGNMENT.md ④「不自然な脱落や重複がないかを確認する」に該当）

### 引用の過剰

第1・2・5歌は全行、第4歌も96%を引用しており、実質的に原文と訳の全文掲載に注釈が続く形になっている。第3歌（70%）と第4歌だけがやや選択的である。

影響は第1歌の講評と同じ。

- **解説が原文に密着しない。** 地の文は「17〜18行の」「100〜102行の」と行番号で参照する書き方が中心で、原語を引いた語釈は少ない。ただし第3歌の `il ben de l'intelletto`、第4歌の `duol sanza martìri`・`sanza speme vivemo in disio`、第5歌の `talento` のように、要所で原語を引く箇所もある
- **注釈の粒度が粗くなる。** 引用ランと直後の地の文が1つの注釈になるため、1節1ランだと30行単位で注釈が1つ付く形になる（見出しの行範囲を付与した後の話である）
- **翻訳テキストの生成が素通しになる。** 第1・2・5歌は全行に訳が付いた状態で抽出されるので、補完のモデル呼び出しが働かない。解説の引用が翻訳工程を兼ねてしまっている

### 事実関係と解釈

**5歌を通して明らかな誤りは見当たらない。** 扱う範囲も広い。

- 第2歌 … 「選ばれた器」＝パウロと『コリントの信徒への手紙二』第12章の「第三の天」、ルチアと `lux` の結びつき、ダンテの視力とルチア信仰、ラケル＝観想的生／レア＝活動的生、マリア→ルチア→ベアトリーチェ→ウェルギリウスという救援の連鎖
- 第3歌 … 門の銘の「権能・知恵・愛」を三位一体に対応づける読み、`il ben de l'intelletto` の説明、「大いなる拒絶」をケレスティヌス5世（1294年退位）としつつピラトなどの異説にも触れる慎重さ、`contrapasso` の説明、カロンら異教の存在が神の摂理の下に組み込まれていること
- 第4歌 … リンボの住人の範囲、`duol sanza martìri`、キリストの冥府降下と旧約の義人、ホメロス・ホラティウス・オウィディウス・ルカヌスの4人、「知る者たちの師」＝アリストテレス、アヴィセンナとアウェロエスへの評価
- 第5歌 … ミノスの尾の巻数、`contrapasso` としての暴風、「愛は高貴な心に宿る」が宮廷恋愛の語彙であること、カイナとジャンチョット・マラテスタ、`Galeotto`＝ガレハウトのイタリア語形

解釈の慎重さも保たれている。第3歌の「大いなる拒絶」、第4歌の七つの城壁（自由七科など複数の解釈に言及）、第1歌の `veltro` は、いずれも諸説を並べて断定を避けている。

一方、第1歌の講評で挙げた弱点――`tra feltro e feltro` の清貧説に触れない、`lonza` の同定の不確かさに触れない、1300年と聖年・白羊宮に触れない、詩人／旅人の二重視点の枠組みがない――は、第2歌以降でも同様である。語釈より場面ごとの主題解説に重心があり、astra と比べると原文の細部への踏み込みがやや浅い。

文体は5歌とも「です・ます調」で統一されており（[`scripts/check_style.py`](../scripts/check_style.py)）、「結び」もすべて備えているため [`scripts/add_conclusion.py`](../scripts/add_conclusion.py) は不要。

### 引用の形式的正確さ

引用ブロック自体はほぼ完璧である。生成直後の時点で、5歌の引用のうち原文がコーパスと一致しないのは第3歌の第1行のみで、これは原文 `‘Per me si va ne la città dolente,` の冒頭の引用符が落ちていた（`extract_translations` はこの1行を破棄するため、第3歌の第1行だけが補完に回っている）。現在は `fix_quote_blocks.py` の再構成によって解消している。

訳文の行が欠けているペア、行番号の重複、範囲外の行番号はいずれもゼロ。[`scripts/check_quote_blocks.py`](../scripts/check_quote_blocks.py) は第1〜4歌が `OK`、第5歌のみ2節が複数ブロックである（複数ブロックは astra にも普通に見られるもので、欠点ではない）。

### 翻訳テキスト

5歌すべて行数が原文と一致し、空行・原文の複写・日本語を含まない行はない。訳の質は第1歌で確認したとおりで、`colle`/`valle`、`peltro`、主客の取り違えといった gemma4-26b が崩した類の誤りはない。

鍵括弧は、生成直後の時点で `fix_brackets.py --check` が第2歌・第3歌・第5歌に各1セグメントの不整合を報告した。いずれもスクリプトで補正できる範囲で、適用済みである。

ただし第1歌の67行――「彼は答えた。『今は人間ではないが、かつては人間であった』」とその行で閉じてしまい、78行まで続く発言が切れている――は `fix_brackets.py` では直らない。判定がセグメント内の未対応の括弧数（`crossing` と `unmatched` の突き合わせ）だけを見ており、この発言はセグメント61〜90に収まるため原文側も訳文側も「またぎ0」で一致してしまうためである。セグメント内で閉じる位置がずれている場合は検出できない。

語の選択で気になったのは第1歌の2箇所。106行 `umile Italia` の「謙虚なイタリア」（ここでの `umile` は『アエネーイス』の `humilem ... Italiam` を踏まえた「低い」であり、道徳的な謙虚さではない）と、73行 `quel giusto` の「敬虔な人物」（原語は「義しい」）である。

### まとめ

解説の中身と翻訳の質は astra と並ぶ。

astra との比較で残る実質的な差は**引用量**だけである。terra は5歌すべてで引用が地の文を上回り、全行に近い量を節冒頭にまとめて置く。後処理を経た astra の被覆（42〜67%）と比べても、後処理前の推定値と比べても差は大きい。論じる箇所だけを、論じる直前に数行ずつ置く形にできれば解消する。

それ以外の形式面――見出しの行範囲がない、第3歌の節範囲の重複、見出し書式の揺れ（第2歌だけ行範囲付き、第3歌だけタイトルが「地獄篇 第3歌」と分かち書き）――は、astra が [ALIGNMENT.md](../ALIGNMENT.md) の後処理で整えている項目であり、モデルの能力差ではない。terra を同じ土俵に載せるには、同じ後処理を通す必要がある。
