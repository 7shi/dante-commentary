# terra

`openai:gpt-5.6-terra` による出力。地獄篇第1〜10歌。

```
uv run scripts/generate.py inferno -c 1-10 -m openai:gpt-5.6-terra -d terra
```

- `01.md`〜`10.md` … 解説記事（commentary）
- `01.txt`〜`10.txt` … 全行の日本語翻訳テキスト。`NN.md` の引用ブロックから抽出した訳を種にして、残りを補完させたもの

[`scripts/fix_brackets.py`](../scripts/fix_brackets.py) と [`scripts/fix_quote_blocks.py`](../scripts/fix_quote_blocks.py) は適用済み。[ALIGNMENT.md](../ALIGNMENT.md) の後処理（引用の追加・節の並べ替え・見出しへの行範囲付与）は未適用。

生成は3つのプロンプトにまたがっている。

| 歌 | プロンプト |
| --- | --- |
| 第1〜5歌 | 改訂前 |
| 第6〜7歌 | 「論じる行だけに絞る」「引用と地の文を交互に置く」を追加 |
| 第8〜10歌 | さらに「見出しは10個前後」「連続する詩行は1ブロックにまとめる」を追加（[b50bbe0](../scripts/generate.py)） |

## 講評

**事実関係と翻訳の正確さは [astra](../astra/README.md) と互角だが、記事としての密度と、後処理で吸収できない手作業の量に差がある。** プロンプトの改訂で引用量と節数はかなり改善したものの、引用は依然 astra より多く、カントによる振れも残る。

### プロンプト改訂の効果

**効いたもの。**

- 節数は改訂2で11・10・12となり、astra と同水準に戻った（改訂前は8前後、第7歌は5節まで落ちていた）
- 「見出しの担当範囲をまとめて引用してから解説する」形は解消し、ブロック数は7〜9から17〜25へ増えた。astra（10〜20）と同等かそれ以上に細かく交互配置されている
- 地の文は3,336字平均から4,513字平均へ増加。第8歌（4,609字）と第10歌（5,641字/62段落）は astra を上回った

**効かなかったもの。**

- 引用被覆は93%→65%まで下がったが、astra の49%には届かない。引用比も57%対49%
- カントによる振れが残る。改訂2でも第9歌は引用比65%・地の文3,288字と改訂前並みで、第10歌（51%・5,641字）との差が大きい
- 段落数は35〜62で、astra（44〜51）より下振れする歌がある

### 事実関係と解釈

第1〜5歌を通読した範囲で明らかな誤りはなく、第6〜10歌の抜き取り確認でも誤りは見つからなかった。扱う範囲も広い。

- 第2歌 … 「選ばれた器」＝パウロと『コリントの信徒への手紙二』の「第三の天」、ルチアと `lux`、ラケル＝観想的生、マリア→ルチア→ベアトリーチェ→ウェルギリウスの救援の連鎖
- 第3歌 … 門の銘の「権能・知恵・愛」と三位一体、`il ben de l'intelletto`、「大いなる拒絶」をケレスティヌス5世としつつ異説にも触れる慎重さ
- 第4歌 … `duol sanza martìri`、キリストの冥府降下、古典詩人4人、アヴィセンナとアウェロエスへの評価
- 第5歌 … ミノスの尾の巻数、宮廷恋愛の語彙、カイナとジャンチョット・マラテスタ、`Galeotto`＝ガレハウト
- 第8歌 … フレギュアスとコロニスの伝承、フィリッポ・アルジェンティとアディマリ家、`meschite`（モスク）が中世西欧の想像力における異質な城郭の表象であるという留保
- 第10歌 … `Iosafàt`（ヨシャファトの谷）、中世のエピクロス理解と歴史上のエピクロス哲学の区別、1300年設定と1302年の追放という二重の時間構造

一方、[astra](../astra/README.md) と比べると原文の細部への踏み込みは浅い。`tra feltro e feltro` の清貧説、`lonza` の同定の不確かさ、聖年や白羊宮、丘と煉獄山の関係、詩人／旅人の二重視点といった枠組みは第1歌以降も現れない。地の文に原語を引いて語釈を加える書き方も、astra ほど一貫していない。

文体は10歌とも「です・ます調」で統一されており（[`scripts/check_style.py`](../scripts/check_style.py)）、「結び」もすべて備えている。

### 翻訳テキスト

10歌すべて行数が原文と一致し、空行・原文の複写・日本語を含まない行はない。`colle`/`valle`、`peltro`、主客の取り違えといった類の誤りもない。

語の選択で気になったのは第1歌の2箇所。106行 `umile Italia` の「謙虚なイタリア」（ここでの `umile` は『アエネーイス』の `humilem ... Italiam` を踏まえた「低い」）と、73行 `quel giusto` の「敬虔な人物」（原語は「義しい」）である。

### 手作業が必要だった箇所

**スクリプトで解消したもの。**

- 引用の原文から記号が落ちた3件（第3歌1行目の `‘`、第7歌1行目の `«»`、第8歌51行目の `».`）。`extract_translations` が破棄するため該当行は補完に回ったが、`fix_quote_blocks.py` の再構成で解消

**手作業が必要だったもの。**

| 箇所 | 内容 |
| --- | --- |
| 第2歌 43・45行ほか | 43行の1行発言を閉じず45行の長い発言を開いていない。入れ子4組を `『』` に直して構造を復元 |
| 第6歌 108行 | 106〜111行の発言を108行で閉じ、111行で二重に閉じていた |
| 第7歌 45・57行 | 40〜48行と52〜66行の発言を途中で閉じ、末尾で二重に閉じていた |
| 第9歌 8〜9行 | 一続きの発言を8行で閉じ9行で開き直していた |
| 第9歌 22・27行 | 20〜33行の発言の内側に、原文にない `「…」` を入れ子で追加していた |
| 第9歌 91〜93行 | 91行で開き99行で閉じたため、92行の地の文が発言の内側に入っていた |
| 第9歌 131行（md） | 訳文の閉じ丸括弧が欠落し、引用ペアとして抽出されなかった |
| 第6歌 引用ブロック | 1詩行ごとに独立したブロックになっていたため（49ブロック）、間の空行32個を除去してから再構成 |
| 第3歌 119行・第9歌 4行 | 訳語がジョージア文字 `ყურადღ(ება)`・デーヴァナーガリー `उतर` のまま出力されていた |

鍵括弧の6件は、いずれも [`scripts/fix_brackets.py`](../scripts/fix_brackets.py) では直らない。同スクリプトの判定はセグメント内の未対応の括弧数（`crossing` と `unmatched` の突き合わせ）だけを見るため、**セグメント内で収支が合ってしまうずれは検出できない**。第9歌22〜27行のように開きと閉じを対で追加した場合は特に見つけにくく、原文の `QuoteSpan` と訳文の括弧スパンを直接突き合わせて初めて判明した。鍵括弧に限れば、astra の同じ範囲（第1〜10歌）で同種のずれは1件だけである。

ただし、**astra が手作業なしで済んだわけではない**。[ALIGNMENT.md](../ALIGNMENT.md) は astra に必要だった手直しの作業記録であり、第1〜10歌についても以下が行われている。

- 引用の追加 … 第1歌（37〜43, 88〜90, 106〜111, 124〜126行）、第2歌（100〜102行）、第3歌（19〜21, 22〜24, 40〜42行）、第5歌（7〜10, 97〜99行）、第6歌（19〜21行）の5歌
- セクションの時系列順への並べ替え … 第1歌
- 見出しへの行範囲の付与・標準化 … 全10歌

つまり手作業の総量そのものは、両者とも歌あたり1件前後で大きくは変わらない。**違うのは種類**である。astra は「本文が言及している行の引用が抜けている」「節の順序が入れ替わっている」という、記事の構成に属する不足で、機械的な検査（本文中の行言及と引用の突き合わせ）で洗い出せる。terra は鍵括弧の閉じ位置や文字化けといった、訳文そのものの不良で、原文スパンとの突き合わせや異種文字の走査といった別の検査が要る。

文字化け2件は astra にはなかった。生成物の検査として、日本語・ラテン文字・数字以外の文字を含む行を報告する仕組みがあると早く気づける。

### まとめ

- **翻訳テキスト**は astra と互角。10歌すべて完備で、難所の誤訳もない
- **解説の事実関係**も互角。「第二の死」＝黙示録由来や三獣の政治的解釈のように、astra にない指摘もある
- **記事の密度**は改訂2で astra に近づいたが、カントによる振れが大きく、語釈の細かさでは届かない
- **手作業の種類**が違う。terra はスクリプト通過後に鍵括弧6件・文字化け2件・引用形式2件が残った。astra も [ALIGNMENT.md](../ALIGNMENT.md) の記録どおり引用追加・節の並べ替え・見出し行範囲の付与を要しており、量ではなく内容の差である

引用量と節数はプロンプトで動かせたが、語釈の密度と出力の安定性は動かなかった。34歌×3篇に広げれば、どちらを使っても歌あたり1件前後の手作業は避けられない。terra の場合はそれが訳文の不良（鍵括弧・文字化け）に寄るため、原文スパンとの突き合わせと異種文字の走査を検査に加えておく必要がある。
