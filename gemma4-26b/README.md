# gemma4-26b

`ollama:gemma4:26b-a4b-it-qat` による出力。

```
uv run scripts/generate.py inferno -c 1 -d gemma4-26b --no-think
```

- `01.md` … 解説記事（commentary）
- `01.txt` … 原文と日本語訳を1行ずつ交互に並べた対訳。`01.md` の引用ブロックから抽出した訳を種にして、残りを補完させたもの

## 講評

結論としては、**読み物としては成立するが、テキストとの逐語的な対応は信頼できない**。26B級のモデルとしては妥当な水準で、下読みや叩き台には使えるが、そのまま資料にはできない。

### 解説（01.md）

構成は良好。「暗い森」「三獣」「ウェルギリウス」「ヴェルトロ」「巡礼の決意」という5部構成は第1歌の読解として標準的で、見出し＋引用＋地の文という指示された形式も守られている。三獣の寓意（豹＝色欲、獅子＝傲慢、狼＝強欲）、ウェルギリウス＝人間理性という配当も通説どおり。

一方で以下の難がある。

- **引用の不正確さ**: 85行を `e 'il mio autore`（正しくは `e 'l mio autore`）と誤記。101行は `che 'l veltro` とだけ引用しており、実際の行（`e più saranno ancora, infin che 'l veltro`）の一部でしかない。抽出スクリプトはこの2行を原文不一致として弾いた
- **固有名詞の誤り**: `veltro` を一貫して「ヴォルトロ」と表記している（ヴェルトロ）
- **訳の誤り**: 130行 `io ti richeggio`（あなたに請う）を「あなたに感謝します」としている
- **取りこぼし**: 121〜123行の「私よりもふさわしい魂」（ベアトリーチェの予告）に触れていない。天国への導き手が交代するという第1歌の要点の一つが落ちている
- 引用は全体で13行のみで、136行に対して被覆はかなり薄い

### 対訳（01.txt）

文体は統一された文語調で、種となった13行と後から補完した123行の間に違和感はない。よく訳せている範囲もかなりある。冒頭の1〜12行、ウェルギリウスの自己紹介（67〜75行）、狼の性質の説明（94〜99行）などは、連続した数行にわたって正確で読みやすい。

一方、崩れる箇所ははっきりしている。**1行を独立した単位として訳すため、複数行にまたがる構文が処理できない**。具体的には次の3つの形で現れる。

**隣接行の重複**（同じ内容が2行以上に繰り返される）

- 13〜15行: 3行すべてが「谷」の話になる。13行は `al piè d'un colle`（丘の麓）なので「谷」は誤りで、14行の内容を先取りしている
- 22〜23行: どちらも「荒れ狂う海から岸へと這い上がった者のように」と丸ごと同一
- 44〜45行: どちらも「私の前に現れたライオンの姿」
- 49〜50行、83〜84行、100〜101行も同様に二重化

**行の取り違え**（隣接行の内容が入れ替わる）

- 76〜80行が最も激しい。78行に76行の訳（「なぜそんなに面倒なことに立ち返るのか？」）が入り、80行に77行の訳（「その愛すべき山を登ろうとしないのか？」）が入る。79行はウェルギリウスへの呼びかけなので、問いと答えが噛み合わなくなっている
- 86行と87行も内容が入れ替わっている

**引用符の乱れ**

- 65行は66行の台詞まで巻き込んで一つの鉤括弧に収め、66行で同じ内容を繰り返す
- 90行、129行、135行のように、台詞の途中の行に閉じ鉤括弧が勝手に付く

語彙レベルの誤訳も残る。

- 17行 `raggi del pianeta`（太陽の光）→「惑星の光」
- 88行 `Vedi la bestia per cu' io mi volsi`（私が引き返す原因となったあの獣を見てください）→「あなたがあの獣によって私を追い払ったところ」と主体を取り違え
- 103行 `peltro`（錫）→「毛皮」、105行 `tra feltro e feltro` に「羊飼い（毛織物）」という原文にない補足
- 106〜107行に「ヴィルジリウス」への言及を勝手に追加している（原文にない）
- 109行 `Questi`（ヴェルトロを指す）を「この獣」と訳し、駆逐する側と駆逐される狼を混同
- 111行「押し戻すまでもなく。（＝押し戻してくれるはずだ。）」のように、自分の訳に自分で注釈を付けて破綻している
- 112〜113行は主客が逆（`per lo tuo me' penso e discerno` はウェルギリウスがダンテのために判断している）
- 125行 `perch' i' fu' ribellante`（私＝ウェルギリウスが背いたゆえ）を「彼はかつて自らの法に背いた」と皇帝の行為にしている
- 130行「あなたに感謝します」（`io ti richeggio` ＝ あなたに請う）は `01.md` の引用から抽出した訳をそのまま引き継いだもので、誤りが解説から対訳へ伝播している

なお生成のたびに崩れる箇所は変わる。別の試行では、7行 `Tant' è amara che poco è più morte` を「死よりもいっそう苦しい」と逆方向に訳したり、55〜56行の構文を追えず原文にない補足を加えて崩壊させたりしていた（今回はどちらも妥当な訳になっている）。ここに挙げた誤りは固定的な傾向ではなく、この規模のモデルではどの行でも起こりうると見るべきである。

## 生成過程での知見

### thinkingは実用にならない

thinkingを有効にしたまま123行の補完を投げると、600秒経っても応答が返らなかった。`--no-think`（`include_thoughts=False`）を指定すると数分で完了する。このサイズのモデルでこの分量のタスクを回すなら `--no-think` は必須。

### 未訳行はプレースホルダーで示す

未訳行をどう示すかで、収束と出力の質が大きく変わった。

| 未訳行の表現 | 残り行数の推移 | 問題 |
| --- | --- | --- |
| 空行 | 123 → 43 → 25 → 24 → 19 → 15 | 頭打ち。空行は見落とされる |
| `【未翻訳】` | 123 → 24 → 12 → 2 → 0 | 訳文の先頭にプレースホルダーが貼り付いた行が9行。さらに `【未翻譯】`（繁体字）や `【未不足】` という自作の変種まで出た |
| `**NEED TRANSLATE**` | 123 → 67 → 8 → 1 → 0 | なし |
| `NEED TRANSLATE` | — | 136行中87行がイタリア語原文の複写になり、実質破綻 |

空行はモデルが見落としやすく、5ラウンド回しても15行が埋まらなかった。日本語のプレースホルダーは訳文と地続きなので、そのまま出力に混入する。`**` を外した `NEED TRANSLATE` では、なぜか大半の行で原文をそのまま複写して返すようになった。強調記号が「ここは通常のテキストではない」という手がかりとして効いているように見える。

なお保存する `01.txt` 側は空行のままで、プレースホルダーはモデルへ渡すときにのみ挿入している。

### 出力の検査は必須

上記の破綻はいずれも、出力を機械的に検査しなければ気付けない形で起きる。現在は補完された行について、

- プレースホルダーがそのまま残っていないか
- 原文と一致していないか
- 日本語文字を含んでいるか

を確認し、通らない行は未訳のまま次のラウンドへ回している。プレースホルダーは `**` の有無どちらの形で返ってきても除去する。この検査を入れた状態では4ラウンドで全行が埋まった。
